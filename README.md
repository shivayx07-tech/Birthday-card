# Happy Birthday, Shreya! 🌟✨

A magical fairytale interactive birthday card web experience created with TanStack Start, React, Tailwind CSS, and Framer Motion.

## Features

- 💌 Interactive 3D opening letter envelope
- 🎶 Magical music box audio
- 🎆 Interactive fireworks canvas & star shower celebrations
- 🎈 Floating lanterns, balloons, and butterflies
- 📸 Photo memory carousel
- 💫 Personalized heartfelt wishes

## Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
